**Goal:** Người điều độ đặt/dời **giờ bắt đầu của một LỆNH SẢN XUẤT** trên một bàn Gantt "một dòng một lệnh", hệ trả ngay **ngày kết thúc** của lệnh; module cũ `xep_lich_2` bị ẩn đường vào.

**Architecture:** Một bảng mới `xep_lich_lenh` chỉ lưu **một** quyết định của người (`bat_dau_at`). Mọi số khác — mốc kết thúc lệnh, mốc từng công đoạn, các đoạn máy chạy trong ca — **tính lúc đọc** bằng engine giờ làm việc đã có (`xep_lich_service.LichXuong` + `_cong_gio_lam`) và thời lượng bước đã có (`lsx_service.thoi_luong_buoc`). Backend phân tầng `routers → services → repositories`; FE là một màn mới hoàn toàn, **không sửa** file nào của màn 2.

**Tech Stack:** FastAPI · SQLAlchemy 2.0 (`Mapped`/`mapped_column`) · Pydantic v2 · pytest (SQLite in-memory) · React + TypeScript + Vite · CSS thuần theo `styles/tokens.css`.

**Spec:** `docs/spec-xep-lich-3.md` (nghiệp vụ + API) và `docs/design-xep-lich-3-ui.md` (UI). Bản phác thảo chạy được: `docs/mockups/xep-lich-3.html`.

## Global Constraints

Áp cho **mọi** task, không nhắc lại ở từng task:

- **KHÔNG có Alembic.** Thêm bảng/cột phải viết vào `backend/app/db_migrations.py` mới lên được DB live/prod. `create_all` chỉ TẠO bảng, không ALTER.

- **Cột Boolean**: `server_default` phải là `false()`/`true()` của SQLAlchemy, **không** `"0"`/`"1"` (vỡ khi Postgres `create_all` trên DB trắng). *Bảng này không có cột Boolean nào, nhưng luật vẫn đứng.*
- **Migration cấm ORM full-select** — backfill phải raw SQL đích danh cột.
- **Số migration kế tiếp**: cao nhất trong repo hiện là `0290_san_xuat_cong_viec_ghi_chu_quy_cach`. Dùng **`0291`** rồi **`0292`**.

- **Giờ = wall-clock naive** ("giờ nhà máy"): tính bằng `_aware()`, trả ra bằng `_naive()`, đúng lối `xep_lich_service`.
- **Pydantic nuốt field im lặng**: field không khai trong schema `Out` bị bỏ **không báo lỗi**. Thêm số nào cũng phải đi hết `dict service` → schema `Out` → type TS.

```python
def _migrate_xep_lich_lenh(db: Session) -> None:
    """Xếp lịch 3 (10/09/2026) — bảng `xep_lich_lenh`, một dòng một LỆNH.

    Bảng MỚI hoàn toàn, không đụng `xep_lich_cong_doan`: module 2 chỉ bị ẩn đường vào, dữ liệu và
    API của nó giữ nguyên. Không backfill — mốc bắt đầu là quyết định của người, không suy được từ
    lịch công đoạn cũ (một lệnh ở bảng cũ có thể có nhiều dòng, nhiều mốc, thậm chí xếp lệch nhau).

    Idempotent: `CREATE TABLE IF NOT EXISTS` + `CREATE UNIQUE INDEX IF NOT EXISTS`.
    """
    ins = inspect(db.get_bind())
    if not ins.has_table("xep_lich_lenh"):
        pg = db.get_bind().dialect.name == "postgresql"
        pk = "SERIAL PRIMARY KEY" if pg else "INTEGER PRIMARY KEY AUTOINCREMENT"
        ts = "TIMESTAMPTZ" if pg else "DATETIME"
        db.execute(text(
            f"CREATE TABLE xep_lich_lenh ("
            f"  id {pk},"
            f"  lsx_id INTEGER NOT NULL REFERENCES lsx(id) ON DELETE CASCADE,"
            f"  bat_dau_at {ts} NOT NULL,"
            f"  created_by INTEGER,"
            f"  created_at {ts} NOT NULL,"
            f"  updated_at {ts} NOT NULL"
            f")"
        ))
    db.execute(text(
        "CREATE UNIQUE INDEX IF NOT EXISTS ix_xep_lich_lenh_lsx "
        "ON xep_lich_lenh (lsx_id)"
    ))
    db.commit()


MIGRATIONS.append(("0291_xep_lich_lenh", _migrate_xep_lich_lenh))
```

```python
"""Xếp lịch 3 — trải thời lượng các bước lên giờ làm việc. HÀM THUẦN, không DB.

Tách khỏi `service.py` có chủ đích: đây là phép tính duy nhất mà cả bốn chỗ tiêu thụ ở §7 của spec
đều đi qua, nên nó phải kiểm được bằng số mà không cần dựng đơn → lệnh → routing.

Dùng khung THEO CA (`lien_tuc=False`) — khác module 2 vốn cho máy chạy trọn ngày. Đây chính là chỗ
"cộng thêm thời gian ngoài ca" mà mục tiêu của module đòi.
"""
from __future__ import annotations

from dataclasses import dataclass, field
from datetime import datetime, timedelta

from ..xep_lich_service import _aware, _cong_gio_lam, _naive, _vao_gio_lam


@dataclass(frozen=True)
class BuocVao:
    """Một bước routing đã quy về SỐ — service lo dịch từ `LsxCongDoan` sang đây."""
    lsx_cong_doan_id: int
    thu_tu: int
    chay_phut: float
    # Bước thuê ngoài: số NGÀY LỊCH chiếm chỗ (`ngay_nhan_dk - ngay_gui_dk`). None = không phải
    # thuê ngoài, HOẶC thuê ngoài mà chưa khai ngày (phân biệt bằng `chay_phut == 0`).
    thue_ngoai_ngay: int | None = None
    la_thue_ngoai: bool = False


@dataclass(frozen=True)
class DoanChay:
    tu: datetime
    den: datetime
    buoc_index: int


@dataclass(frozen=True)
class MocBuoc:
    lsx_cong_doan_id: int
    thu_tu: int
    bat_dau: datetime
    ket_thuc: datetime
    chay_phut: float


@dataclass(frozen=True)
class KetQuaTrai:
    bat_dau: datetime
    ket_thuc: datetime
    da_doi: bool
    chay_phut: float
    doan: list[DoanChay] = field(default_factory=list)
    buoc: list[MocBuoc] = field(default_factory=list)
    ghi_chu: list[str] = field(default_factory=list)


def trai_lich(moc: datetime, buoc: list[BuocVao], lich) -> KetQuaTrai:
    """Trải `buoc` (sắp theo `thu_tu`) từ `moc`, trả mốc lệnh + mốc từng bước + các đoạn chạy.

    Mốc rơi vào nghỉ/ngoài ca/ngày nghỉ thì TRƯỢT tới đầu khoảng chạy được gần nhất và bật
    `da_doi` — làm tròn cho phép cộng có nghĩa, KHÔNG phải cửa chặn (spec §3.2).
    """
    dau = _vao_gio_lam(_aware(moc), lich)
    da_doi = _naive(dau) != moc
    con: datetime = dau
    doan: list[DoanChay] = []
    moc_buoc: list[MocBuoc] = []
    ghi_chu: list[str] = []
    tong_chay = 0.0

    for i, b in enumerate(sorted(buoc, key=lambda x: (x.thu_tu, x.lsx_cong_doan_id))):
        b_dau = con
        if b.la_thue_ngoai:
            if b.thue_ngoai_ngay is None:
                ghi_chu.append(
                    "Bước gia công ngoài chưa khai ngày gửi/nhận — lệnh có thể kết thúc muộn hơn."
                )
            else:
                # NGÀY LỊCH: nhà cung cấp không chạy theo ca của xưởng.
                con = con + timedelta(days=b.thue_ngoai_ngay)
        elif b.chay_phut > 0:
            doan.extend(_cat_doan(b_dau, b.chay_phut, i, lich))
            con = _cong_gio_lam(con, b.chay_phut, lich)
            tong_chay += b.chay_phut
        moc_buoc.append(MocBuoc(
            lsx_cong_doan_id=b.lsx_cong_doan_id, thu_tu=b.thu_tu,
            bat_dau=_naive(b_dau), ket_thuc=_naive(con), chay_phut=b.chay_phut,
        ))

    return KetQuaTrai(
        bat_dau=_naive(dau), ket_thuc=_naive(con), da_doi=da_doi,
        chay_phut=tong_chay, doan=doan, buoc=moc_buoc, ghi_chu=ghi_chu,
    )


def _cat_doan(tu: datetime, chay_phut: float, buoc_index: int, lich) -> list[DoanChay]:
    """Cắt `chay_phut` từ `tu` thành các đoạn CHẠY LIỀN MẠCH, bỏ nghỉ giữa ca / ngoài ca / ngày nghỉ.

    Đi theo chính các khoảng làm-việc mà `lich.next_interval` cấp — cùng nguồn `_cong_gio_lam` đi,
    nên đoạn không bao giờ lệch mốc kết thúc. Tổng các đoạn LUÔN bằng `chay_phut` (test chốt).
    `next_interval` tự chặn vòng bằng `_MAX_NGAY`, không có đường lặp vô hạn.
    """
    ra: list[DoanChay] = []
    con = float(chay_phut)
    cur = tu
    while con > 1e-9:
        iv = lich.next_interval(cur)
        if iv is None:          # hết khung trong tầm 400 ngày — trả những gì đã cắt được
            break
        s, e = iv
        cur = max(cur, s)
        an = min((e - cur).total_seconds() / 60, con)
        if an <= 0:             # con trỏ đúng mép phải khoảng: nhảy sang khoảng kế
            cur = e
            continue
        ra.append(DoanChay(
            tu=_naive(cur), den=_naive(cur + timedelta(minutes=an)), buoc_index=buoc_index,
        ))
        con -= an
        cur = cur + timedelta(minutes=an)
    return ra
```

```python
            .where(XepLichLenh.bat_dau_at <= den)

            select(LsxCongDoan)
            .where(LsxCongDoan.lsx_id.in_(lsx_ids))
            .order_by(LsxCongDoan.lsx_id, LsxCongDoan.thu_tu)
        ).scalars())
```

```python
def _ngay_thue_ngoai(cd) -> int | None:
    """Số NGÀY LỊCH một bước gia công ngoài chiếm chỗ. `None` = chưa khai đủ để biết.

    Hai nguồn, ưu tiên nguồn KHAI TAY vì nó là cam kết của nhà cung cấp:
    1. `van_chuyen_ngay` (MỘT chiều, nên nhân 2) + `gia_cong_ngay`;
    2. `ngay_nhan_dk - ngay_gui_dk` nếu khai cả hai mốc.

    Cột đã tra ở `models/lsx.py:297-305`; cờ nhận biết là `loai_buoc == LB_THUE_NGOAI` chứ KHÔNG
    có cột boolean `gia_cong_ngoai` nào.
    """
    vc, gc = cd.van_chuyen_ngay, cd.gia_cong_ngay
    if vc is not None or gc is not None:
        return int(round(float(vc or 0) * 2 + float(gc or 0)))
    if cd.ngay_gui_dk and cd.ngay_nhan_dk:
        return max(0, (cd.ngay_nhan_dk - cd.ngay_gui_dk).days)
    return None
```
